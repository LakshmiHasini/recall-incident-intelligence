# Demonstrating the actual application

Use real incident data you are permitted to share, or clearly label any synthetic scenario. This is a walkthrough of live functionality, not a separate mocked implementation.

1. Open the workspace and Connections. Test the live Hindsight connection.
2. Create an incident with a service, symptoms and redacted log excerpts.
3. Investigate. With no relevant history, inspect how the answer acknowledges missing evidence.
4. Add an attempted action to the timeline and mark it failed, with the actual observation.
5. Resolve the incident with a confirmed cause, fix and verification. Show successful memory sync.
6. Open another session and create a related incident.
7. Investigate and inspect the returned source facts and the earlier failed-action context.
8. Amend a confirmed outcome if new evidence changes it; sync the newer version and inspect the resulting knowledge.

For a controlled no-memory comparison, hold the incident, prompt and model constant and change only memory access. Do not describe different canned outputs as an experimental comparison.
